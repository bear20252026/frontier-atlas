## Audit state

Frontier I and the five remaining benchmark volumes are offline pending a line-by-line audit. Their 542 entries will return only when approved individually. The repositories remain in place; their GitHub Pages sites are down.

Live: https://bear20252026.github.io/frontier-atlas/

The current atlas covers 225 entries across Paper, Nodevember, Video to Game, GTA Shenzhen and Frontier Studio. Paper contains its own 112 pieces; Nodevember and Video to Game stay in their own source repositories; GTA Shenzhen embeds a light cover page and opens the full playable city on Enter; Frontier Studio carries 61 complete works from 53 repositories under its own `source/` tree, with a local demo for every card. The Atlas no longer publishes a global taxonomy while the approved set is being rebuilt.
